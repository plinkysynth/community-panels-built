# MPE Test

A test of MPE input and output for Plinky 12.

It presents two large play surfaces, each with a brightness slider mapped to
Plinky's sample-start / wavetable-position parameter. It accepts normal MIDI on
channels 1 and 16, plus MPE for up to two zones with per-note pitch bend,
brightness, and pressure.

It also sends data in MPE format. The mode pads below the play surfaces open the
usual synth edit and preset load/save pages, using the same parameter order as
Toadstep and Blocks.
